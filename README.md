## 👋 Sobre mí

Soy **Ingeniero en Informática especializado en Desarrollo de Sistemas**, con foco en backend y arquitectura de servicios. Diseño y construyo APIs y servicios aplicando principios SOLID, Domain-Driven Design (DDD) y arquitectura hexagonal.

Mi experiencia incluye bases de datos SQL y NoSQL, optimización de consultas, caché con Redis. También trabajo con entornos containerizados con Docker y pipelines de CI/CD con GitHub Actions.

Mi enfoque prioriza la correctitud, la seguridad y la mantenibilidad, con observabilidad mediante logging estructurado y métricas, y calidad de código mediante testing automatizado.

🔭 Actualmente profundizando en: **backend con Node.js y JavaScript**.

```text
Diseño de API  →  Lógica de dominio  →  Datos e integraciones  →  Listo para producción
```

## 🧭 Cómo construyo software

- Empiezo por el problema y el dominio antes de elegir patrones o infraestructura.
- Diseño contratos explícitos y valido toda entrada en los bordes del sistema.
- Protejo las reglas críticas con tests automatizados y restricciones a nivel de datos.
- Considero seguridad, observabilidad y fallos parciales desde la etapa de diseño.
- Elijo la solución más simple que pueda mantenerse con confianza en producción.
